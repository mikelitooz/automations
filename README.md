# Automation & AI Agent Portfolio
By Micheal Ifeanyi

## Overview
This repository contains the source code for my production-grade automation projects, focusing on **Recruitment Tech** and **Real Estate AI**.

## Key Projects included:
1.  **Headhunter Agent (Python/n8n):**
    * Automated LinkedIn scraping and email verification.
    * Integrates with HubSpot CRM via API.
2.  **Real Estate RAG Chatbot:**
    * Uses OpenAI API and Vector Embeddings to answer property queries.
    * Includes error handling for rate limits.

## Tech Stack
* **Languages:** Python 3.10+, SQL
* **Automation:** n8n Workflows (JSON exports included)
* **AI:** OpenAI API, LangChain
